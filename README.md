# SCOUT 马戏星探 · v2.0.1

两至五人的网页桌游，支持电脑练习、好友组房、手机浏览器、断线恢复与逐轮成绩。

当前源码来自 `SCOUT_v2.0.1_完整包`，包含双人规则修正版。仓库保存源码与依赖锁定文件，不包含 Windows 运行环境、node_modules、本地房间数据库或会话凭证。

## 运行

安装 Node.js **24.22.1**，在项目目录执行：

```sh
npm ci
npm start
```

本机默认打开 <http://localhost:3210>。同一网络下的其他设备使用启动窗口显示的局域网地址。不要直接打开 `public/index.html`。

Windows 用户也可在安装依赖后双击 `启动游戏.bat`。完整离线分发包另带运行环境；从 GitHub 下载源码时需要自行安装 Node.js 与依赖。

## Render 部署

保留原服务名 `scout-game` 与免费实例配置。构建命令为 `npm ci`，启动命令为 `node server.js`；`.node-version` 和 `render.yaml` 指定 Node.js 24.22.1，供内置 SQLite 使用。若控制台配置了 NODE_VERSION，以控制台值为准，请保持相同版本。

现有站点地址：<https://scout-game-i4wj.onrender.com>。仓库提交成功不等于部署完成，请在该地址的 `/health` 查看是否返回 `{"ok":true,"version":"2.0.1"}`。

通过公网地址打开时，“邀请好友”分享当前站点的房间链接；通过 localhost 打开时，提供主机的局域网地址。

**免费 Render 实例使用临时文件系统**：休眠、重启或重新部署可能清除本地 SQLite 房间与成绩，不能据此承诺云端永久存档。普通短暂断网恢复与服务器存储丢失是两种不同情况。详见 [Render 免费服务说明](https://render.com/docs/free)。

## 双人规则

- 仅有演出和挖角两种行动，不使用“挖角并演出”。
- 每人每轮 3 枚自己的挖角筹码，每次只取 1 张并支付 1 枚；整轮最多 3 次。
- 双人挖角后仍由本人行动，不给对手发筹码。演出不会补回预算；下一轮才恢复 3 枚。
- 无法演出且次数耗尽时结算，未用筹码计分。
- 两轮各使用 22 张牌，每人 11 张，第二轮使用预留牌并轮换起始玩家。

三至五人局的普通挖角取 1 张后立即换人，特殊行动每轮一次。
